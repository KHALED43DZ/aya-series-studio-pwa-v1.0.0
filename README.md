# مسلسل آية (PWA) — الإصدار 1.1.0

تطبيق لتوليد مسلسل تعليمي كامل للأطفال: تختار موضوعاً، فيضع Gemini خطة الحلقات تلقائياً، ثم يولّد برومبتات الأماكن والمشاهد لكل حلقة بأسلوب Pixar ثابت، جاهزة للصق في Google Flow.

- آية تُذكر باسمها فقط في المشاهد، وصورتها المرجعية تضيفها أنت في Flow.
- لا يوجد توليد صور داخل التطبيق، والمزوّد الوحيد هو Gemini.
- الحوار مشكول ويُدرج داخل برومبت كل مشهد، والفيديوهات تُولَّد بلا موسيقى، ولكل حلقة برومبت موسيقى واحد يُضاف في المونتاج.

## الرفع إلى GitHub Pages

1. أنشئ **مستودعاً جديداً مستقلاً** (مثلاً `aya-series`). لا تضعه داخل مستودع تطبيق «استوديو ريلز Flow».
2. ارفع **محتويات** هذا الملف بعد فك ضغطه إلى جذر المستودع: `index.html` و`sw.js` و`manifest.webmanifest` و`.nojekyll` ومجلد `icons`.
3. من **Settings ← Pages** اختر: Deploy from a branch، الفرع `main`، المجلد `/ (root)`، ثم Save.
4. الرابط: `https://USERNAME.github.io/aya-series/`

## التثبيت كتطبيق

- أندرويد (Chrome): القائمة ⋮ ← «تثبيت التطبيق».
- آيفون (Safari): مشاركة ← «إضافة إلى الشاشة الرئيسية».

## ملاحظات

- مفاتيح Gemini تُحفظ في متصفحك فقط ولا تُرفع إلى GitHub.
- المسلسلات تُحفظ في المتصفح؛ استعمل «تصدير كل المسلسلات» للنسخ الاحتياطي.
- عند تعديل `index.html` لاحقاً غيّر `VER` فيه ورقم `CACHE` في `sw.js` ليصل التحديث للمستخدمين.
- أسلوب Pixar ثابت في الثابت `STYLE` داخل `index.html`.
